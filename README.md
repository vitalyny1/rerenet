# BUYSELLEXCHANGE

A general-purpose marketplace prototype for buying, selling, and exchanging products, services, digital goods, ideas, and opportunities.

## Current prototype
- Browse sample listings and filter by category and listing type
- Search and sort listings
- Post a listing (sale, service, exchange, free, or wanted)
- Make an offer or propose an exchange
- View locally saved activity

## Important
This is a front-end prototype. Listings and activity are stored in the current browser only. It does not yet include user accounts, shared server storage, secure messaging, checkout, payment processing, seller payouts, moderation, or dispute resolution.

Hosted through the existing Cloudflare Pages project: https://rerenet.pages.dev
